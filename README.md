# Isogram: AI Text Detection

Isogram is a simple PyTorch project for detecting whether an English essay is
human-written or generated by a large language model. It follows the course
proposal: DAIGT v2 is the implementation dataset, Kaggle's LLM Detect AI
Generated Text competition is background only, and the deployed service returns
`{"prob_ai": float, "model_version": string}` from `POST /predict`.

The core rule is simplicity: custom PyTorch models and training loops, no
scikit-learn, no Hugging Face `Trainer`, and no Hugging Face `pipeline()`.

## Public Repo Hygiene

This repository is prepared for public use under a pseudonymous account. Do not
commit real names, personal email addresses, Kaggle credentials, API keys, raw
datasets, trained checkpoints, virtual environments, or local machine paths.

The intended committed artifacts are source code, tests, Docker/project files,
and small JSON metric reports. Runtime outputs stay local:

- raw and processed data: `data/`
- trained checkpoints: `artifacts/`
- local environments and caches: `.venv/`, `.pytest_cache/`, `__pycache__/`
- secrets: `.env`, `kaggle.json`, `.kaggle/`
## Setup

Use Python 3.11 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev,kaggle]"
```
## Data

The implementation dataset is DAIGT v2:
`thedrcat/daigt-v2-train-dataset`.

With Kaggle credentials configured:

```bash
python -m isogram.data.prepare --download
```

Keep Kaggle credentials outside the repository, preferably in
`~/.kaggle/kaggle.json`. The repo ignores `kaggle.json` and `.env` files as a
backup guard.

Or download the dataset manually from Kaggle, place the CSV under
`data/raw/daigt-v2/`, then run:

```bash
python -m isogram.data.prepare --raw-path data/raw/daigt-v2
```

Preparation writes deterministic 80/20 stratified splits to
`data/processed/train.csv` and `data/processed/val.csv`.
