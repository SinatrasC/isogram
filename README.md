# Isogram: AI Text Detection

Isogram is a Python package for classifying English essay text as either human-written or generated by a large language model. It includes data loading, dataset standardization, PyTorch Lightning training, MLflow logging, DVC-managed data artifacts, and a FastAPI prediction service.

## Problem Statement

The project builds a service that receives essay text and returns the estimated probability that the essay was generated by an AI system. The task is related to the Kaggle “LLM - Detect AI Generated Text” competition, but the implementation uses its own training pipeline and a curated Hugging Face dataset instead of depending on the hidden Kaggle test set.

The model API accepts:

```json
{ "text": "Essay text goes here." }
```

The service returns:

```json
{ "prob_ai": 0.73, "model_version": "deberta-v1" }
```

## Data

The default dataset builder creates standardized CSV splits under `data/processed/main/`. It downloads the project dataset from Hugging Face:

- `sinatras/isogram-ai-text-detection-splits`

The downloaded data is already split into train/validation/test partitions and keeps provenance columns: `source_dataset`, `source_detail`, `source_license`, and `upstream_url`.

## Models

The baseline model is a character-level CNN trained with binary cross-entropy. It is intentionally small, fast on CPU, and gives a real model score rather than a dummy baseline.

The main model is a DeBERTa-v3-base encoder with a one-logit classification head. Training uses PyTorch Lightning, AdamW, BCEWithLogitsLoss, and sigmoid probabilities at inference.

## Metrics

Training and evaluation report ROC-AUC, PR-AUC, precision, recall, F1, Brier score, threshold counts, and validation loss. These cover ranking quality, threshold behavior, calibration, and loss optimization.

## Setup

Use Python 3.11 or newer. `uv` is the recommended dependency manager:

```bash
uv sync --extra dev --extra hf --extra mlops --extra docs
source .venv/bin/activate
uv run pre-commit install
```

Optional Kaggle support can be installed with `--extra kaggle` if you want to reproduce the older DAIGT-only preparation path.

## Data Commands

Build or fetch the default dataset:

```bash
uv run isogram data
```

The command first tries DVC pull for the configured split files. If they are not available in local DVC storage, it calls the public download/build path.

To force a rebuild with a smaller sample:

```bash
uv run isogram data data.hf_sample_rows=2000 --rebuild=True
```

## Training

Start MLflow before normal training because the default config logs to `http://127.0.0.1:8080`:

```bash
uv run mlflow server \
  --backend-store-uri sqlite:///mlflow.db \
  --default-artifact-root ./mlruns \
  --host 127.0.0.1 \
  --port 8080
```

Train the baseline:

```bash
uv run isogram train model=char_cnn
```

Train the main model:

```bash
uv run isogram train model=deberta
```

Train both configured models:

```bash
uv run isogram train_all
```

For a quick local smoke run without an MLflow server:

```bash
uv run isogram train model=char_cnn trainer.limit_rows=512 model.max_epochs=3 logging.enabled=false
```

Training writes checkpoints to `artifacts/checkpoints/`, reports to `reports/`, resolved Hydra configs to `reports/run_configs/`, and three plot files to `plots/`.

## Evaluation

```bash
uv run isogram evaluate model=char_cnn logging.enabled=false
```

The evaluation command uses the configured checkpoint and test split, then writes a metrics report under `reports/`.

## Serving

```bash
uv run isogram serve model=char_cnn serve.checkpoint=artifacts/checkpoints/char_cnn_main.pt
```

Open `http://127.0.0.1:8000`, or call:

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text":"This essay argues that careful source evaluation matters."}'
```

## DVC

DVC is initialized with two local remotes:

- `data`: `.dvc_storage/data`
- `models`: `.dvc_storage/models`

Reproduce the data stage:

```bash
uv run dvc repro build_dataset
```

Push artifacts to the configured local DVC data remote:

```bash
uv run dvc push -r data
```
